<objective>
## Goal
Montar a bancada que põe o mesmo clipe, o mesmo efeito e os mesmos valores no Resolume e no
OpenLume, captura as duas saídas e mede a diferença; e, com ela, deixar **Delay RGB, Trails e
Threshold** iguais aos do Resolume nos controles (mesmos controles, ordem, faixas, padrões e
presets) e na tela.

## Purpose
O Felipe quer os efeitos do Resolume no OpenLume, copiados, não efeitos próprios
("não quero efeitos próprios, quero copiar"). Hoje os ~95 efeitos do OpenLume têm o nome certo
mas são aproximações (o Delay RGB tem um controle só). Sem uma bancada que compare de verdade,
"igual" é palpite. Esta bancada serve a todos os lotes seguintes da fase.

## Output
- `tools/compare/`: cliente REST do Resolume, captura das duas saídas, comparação com número e
  imagem lado a lado (Resolume | OpenLume | diferença)
- `referencia-resolume/FICHAS.md`: ficha de controles de todos os efeitos de vídeo, tirada da
  API REST do Resolume (`GET /effects` + parâmetros de cada efeito posto numa camada)
- Delay RGB, Trails e Threshold refeitos em `app/effects*.js`
- Relatório do lote com as imagens lado a lado, para o Felipe aprovar
</objective>

## AC-1: Ficha de controles vinda do Resolume
```gherkin
Given o Resolume aberto com o servidor web ligado (porta 8080)
When roda `node tools/compare/resolume.mjs fichas`
Then sai `referencia-resolume/extraido/effects-rest.json` com todos os efeitos de vídeo de GET /effects
And para cada efeito: nome, e cada controle com nome, tipo (faixa, liga/desliga, lista com opções), mínimo, máximo, padrão e unidade
And `referencia-resolume/FICHAS.md` lista isso em texto, um efeito por seção
```

## AC-2: Bancada lado a lado
```gherkin
Given o mesmo clipe de teste aberto na camada 1 dos dois programas
When roda `node tools/compare/compare.mjs "Threshold" --set "<controle>=<valor>"`
Then o Resolume recebe o efeito e os valores pela API REST e o OpenLume pelo CDP (porta 9333)
And as duas saídas são capturadas no mesmo tamanho (1920×1080 reduzido para 960×540)
And sai um PNG Resolume | OpenLume | diferença e um número: diferença média por pixel (0–255)
And a bancada se recusa a comparar se a captura do Resolume vier preta ou igual a uma tela parada (captura falsa)
```

## AC-3: Os três efeitos iguais nos controles
```gherkin
Given a ficha do Resolume de Delay RGB, Trails e Threshold
When abro cada um no painel Clipe do OpenLume
Then tem os mesmos controles, na mesma ordem, com as mesmas faixas, padrões e opções de lista
And os rótulos ficam em português (regra do projeto), com o nome do Resolume guardado no efeito para a bancada achar o par
```

## AC-4: Os três efeitos iguais na tela
```gherkin
Given cada efeito com os valores padrão e com mais três combinações de valores
When a bancada compara
Then Threshold (efeito parado) fica com diferença média ≤ 3 em 0–255
And Delay RGB e Trails (efeitos que dependem do tempo) são comparados com o clipe parado num quadro e depois trocado de quadro, depois de N quadros fixos, e ficam com diferença média ≤ 8
And quando algum não chegar lá, o relatório diz qual, quanto deu e por quê
```

## AC-5: Sem código do Resolume
```gherkin
Given os arquivos novos e alterados do plano
When procuro trechos dos shaders extraídos (`referencia-resolume/extraido/shaders`) ou dos `.wired`
Then nada aparece: cada efeito é escrito do zero a partir do que a bancada mostra e da ficha da API
```
