<objective>
## Goal
Acrescentar **Acuarela, Tilt Shift e CRT** ao OpenLume, com os mesmos nomes, controles, ordem, faixas, padrões
e presets do Resolume 7.28, e com a imagem conferida lado a lado na bancada, usando os mesmos valores.

## Purpose
A regra do projeto é copiar os efeitos do Resolume, não inventar outros. A Aquarela foi pedido do Felipe, o
Tilt Shift já tem medição começada e o CRT é visual e muito usado. Nenhum dos três precisa de modelo de IA novo.

## Output
- Os três efeitos em `app/effects2.js`, com `rparams` para a bancada
- Fichas dos três em `referencia-resolume/FICHAS.md`
- Medições e números no `tools/compare/README.md`
- Uma beta instalada no CAIOPRADO e publicada como pré-lançamento
</objective>

<acceptance_criteria>

## AC-1: Iguais por fora
```gherkin
Given a ficha de cada efeito lida pela API REST do Resolume 7.28
When o efeito é aberto no painel do OpenLume
Then nome, controles, ordem, faixas, valores padrão e presets batem com a ficha
And a interface segue em português, como nos efeitos já copiados, com `rparams` ligando cada controle ao nome no Resolume
```

## AC-2: Iguais na tela
```gherkin
Given o mesmo clipe e os mesmos valores nos dois programas
When a bancada compara o padrão e cada controle em pelo menos dois valores além do padrão
Then a diferença média de cada caso é registrada no README, em /255, junto com a imagem Resolume | OpenLume | diferença
And o limite de aprovação é definido antes de escrever cada efeito, a partir da primeira medição, e registrado no README
And todo caso acima do limite é corrigido ou fica registrado como diferença aberta, com a causa
```

## AC-3: Efeitos com variação no tempo
```gherkin
Given um efeito cuja imagem muda de um quadro para outro, como ruído ou cintilação do CRT
When ele é comparado com o Resolume
Then a comparação usa medidas estatísticas sobre vários quadros, como média, variância e frequência
And o resultado não é dado como igual a partir de um único quadro
```

## AC-4: Controles funcionam de verdade
```gherkin
Given um dos três efeitos no ar
When cada controle é movido com mouse real pelo CDP
Then o valor chega ao motor e a imagem muda quando o Resolume também muda com aquele controle
And nenhum controle fica sem efeito sem que isso também aconteça no Resolume
```

## AC-5: Nada do que existia quebra
```gherkin
Given os três efeitos acrescentados
When o selftest roda
Then todas as verificações passam, incluindo uma nova para cada efeito
And uma composição com os três efeitos salva, abre de novo e mantém os valores
And a composição continua em pelo menos 30 qps com um efeito por vez em 1920×1080 nesta máquina, ou o custo medido fica registrado como diferença aberta
```
