Conectar celular

Aponte a câmera do celular para o código. O celular e este computador precisam estar no mesmo Wi-Fi.

Ou digite no navegador do celular:
http://192.168.0.10:4747

Nada para instalar: é uma página. Vários celulares podem entrar ao mesmo tempo; cada dedo vira um toque.

Pasta de plugins

Cada plugin é uma pasta dentro de Documentos/OpenLume/plugins. O OpenLume lê a pasta ao abrir; para instalar, é só copiar a pasta para lá.

plugins/
  fluido/        plugin.js · icone.png
  particulas/    plugin.js · icone.png
  neon/          plugin.js · icone.png
  bolinhas/      plugin.js · icone.png

Por dentro, um plugin diz o que é, que controles tem e o que faz a cada quadro:

export default {
  nome: 'Fluido',
  tipo: 'fonte',            // ou 'efeito' (recebe a imagem da camada)
  toque: true,              // recebe o dedo do celular e o mouse
  parametros: {
    estilo: { tipo: 'lista', opcoes: ['fogo', 'fumaça', 'tinta', 'arco-íris'] },
    raio:   { tipo: 'faixa', min: 0.05, max: 1, padrao: 0.25 },
  },
  iniciar(gl, tela) { … },     // cria texturas e shaders na placa de vídeo
  toque(dedo) { … },           // dedo = { id, x, y, dx, dy, apertado }
  quadro(gl, dt, p) { … },     // desenha um quadro; p = valores dos controles
}

Os controles aparecem sozinhos no painel Clipe e no celular, e podem ser ligados ao MIDI, ao som e ao Autopilot como os dos geradores.
